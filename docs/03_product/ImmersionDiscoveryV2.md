# Vision

Immersion Discovery는 Molip의 대표 기능이다.

Molip는 사용자의 행동을 평가하지 않는다.

대신 사용자가 반복적으로 반응하는 대상을 발견하고,
그 안에 숨어 있는 몰입 가능성을 보여준다.

Immersion Discovery는

"당신은 무엇에 반복적으로 반응합니까?"

라는 Molip의 핵심 질문을
제품으로 구현한 기능이다.

---

# Why V2

V1은

현재 기록을 기반으로
몰입 가능성을 제시한다.

하지만

장기 변화

반복 패턴

몰입의 성장

까지는 충분히 보여주지 못한다.

V2는

시간을 활용하여

몰입의 가능성을 발견하는 것을 목표로 한다.

---

# Core Concept

Molip는

사용자가 좋아한다고 말한 것을 보여주는 서비스가 아니다.

사용자가

실제로 반복적으로 반응한 것을

발견하는 서비스이다.

몰입은

추천하는 것이 아니라

발견하는 것이다.
