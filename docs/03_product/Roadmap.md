# Product Vision

Molip는 기록 앱이 아니다.

Molip는 사용자가
자기 자신을 이해하고,
발견하고,
만들어 갈 수 있도록 돕는 서비스이다.

제품은 단순히 기능을 늘리는 것이 아니라,
사용자의 자기이해를 더 깊게 만드는 방향으로 성장한다.

---

# Roadmap Philosophy

우리는 기능의 개수를 목표로 하지 않는다.

새로운 기능은 반드시 아래 중 하나를 만족해야 한다.

- 자기이해를 더 깊게 만든다.
- 시간의 가치를 더 크게 만든다.
- 몰입을 더 잘 발견하도록 돕는다.

그렇지 않다면 만들지 않는다.

# Development Rule

새로운 기능을 추가하기 전에 질문한다.

이 기능은

사용자가

자기 자신을 더 잘 이해하도록 만드는가?

YES

↓

Roadmap 후보

NO

↓

개발하지 않는다.
